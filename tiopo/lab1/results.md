# Результаты выполнения ЛР № 1

Проверено 13 сентября 2026 года на окончательных исходниках лабораторной в ветке `TIOPO-1`. Среда: macOS 26.6.2 arm64, Go 1.26.3, Node.js 26.7.0, Python 3.14.6. Автономный запуск выполнен в Docker на Linux arm64 с Go 1.26.3 и Node.js 24. Изменения оставлены в рабочей копии без коммита.

## Итог

- **412 из 412 сценариев успешно выполнены**, пропущенных и потерянных при экспорте в Allure нет.
- **Покрытие строк: 77,84% — 2923 / 3755**, по атрибутам Cobertura XML, созданного `gocover-cobertura`.
- **Покрытие ветвей: 66,64% — 737 / 1106**, сумма результатов 22 запусков `gobco -branch`.
- Go statement coverage: **77,0%**. Это отдельная метрика, не покрытие строк или ветвей.
- В каждом прогоне лабораторной зафиксированы **22 тестовых процесса**. При `-p=1` общее число осталось 22, пакеты исполнялись последовательно.

## Выполненные проверки

Все перечисленные команды завершились с кодом **0**:

```sh
make coverage
make coverage-branch
make allure-report
make test-unit-race
make test-unit-shuffle SEED=42
make test-unit-shuffle SEED=42    # повтор для сравнения порядка
make test-unit-shuffle SEED=2026
make test-processes
go test ./... -count=1 -timeout=120s
make lab1-offline-image
make test-unit-offline
```

В обычном прогоне с покрытием, race, двух seed и последовательном прогоне выполнены все **412** сценариев. `go test ./...` дополнительно проверил компиляцию остальных Go-пакетов и тест корректности Allure при ошибке `t.Cleanup`. Интеграционные тесты с отдельным build tag в этот запуск не входят.

Порядок событий запуска тестов сравнивался **внутри каждого пакета**, независимо от перемешивания вывода разных процессов. Два прогона с seed 42 дали одинаковый порядок во всех 22 пакетах. Seed 2026 изменил порядок в 21 пакете; в `service/analyze` перестановка совпала, что допустимо для разных seed. Параметры seed и PID доступны в Allure.

Финальный Docker-образ пересобран после исправлений. Запуск с `--network none` выполнил **412 / 412** сценариев и сформировал самостоятельный HTML Allure. JSON-сводка генератора Allure также содержит `total=412`, `passed=412`, `singleFile=true`.

Дополнительно выполнены адресные проверки `go vet`, race и shuffle сервисов и репозиториев. Обновление/удаление заданий планировщика и работа HealthChecker повторены по десять раз. Проверка оболочки запуска с намеренно падающими внешними командами подтвердила: исходный код тестов 42 сохраняется при последующих ошибках сводки, покрытия и Allure; попытка формирования отчёта всё равно выполняется.
