# Выводы по ЛР №6

OpenTelemetry Go SDK 1.41.0 передаёт 100% spans пакетами по OTLP/HTTP в Collector 0.140.0; Collector сохраняет OTLP JSONL и отправляет трассы в Tempo 2.9.0 во время нагрузки. Запуск `20261124t091051-515010` содержит 11 завершённых опытов: четыре режима ramp, четыре stress и три soak-0. В измерительных окнах учтены 97 263 запроса и 150 653 spans.

## CPU приложения и нагрузка

| Профиль | Baseline, CPU с | Trace | Debug | Trace + debug |
|---|---:|---:|---:|---:|
| ramp | 81.718 | 84.086 (+2.90%) | 81.683 (-0.04%) | 84.396 (+3.28%) |
| stress | 74.760 | 75.732 (+1.30%) | 76.446 (+2.26%) | 76.097 (+1.79%) |
| soak-0 | 73.249 | нет завершённого опыта | 70.900 (-3.21%) | 71.171 (-2.84%) |

В ramp трассировка увеличила наблюдаемый CPU API на 2.90%, совмещённый режим — на 3.28%. Медиана RPS составила 61.9 в baseline, 39.6 с трассировкой и 50.0 с обоими средствами; доля неожиданных ответов — 9.10%, 13.05% и 11.70%. HTTP p50 равен 3 мс во всех четырёх режимах ramp; низкая медиана задержки соседствует с ошибками под перегрузкой.

В stress медиана RPS равна 36; сравнение CPU следует читать вместе с долей неожиданных ответов из [полной таблицы](results.md). В завершённых опытах soak-0 медиана RPS равна 36, HTTP p50 — 1 мс, неожиданных ответов нет. Наблюдаемые отрицательные Δ CPU в отдельных режимах описывают эту серию.

## Память и средства мониторинга

| Компонент | CPU за опыт, с: min–max | Медиана RAM по опытам, MB: min–max |
|---|---:|---:|
| api | 70.900–84.396 | 15.06–18.18 |
| collector | 0.461–1.064 | 8.72–8.74 |
| otel-collector | 0.016–0.229 | 26.41–42.14 |
| tempo | 0.217–1.827 | 25.11–237.68 |

API включает создание spans, пакетный SDK и OTLP-экспорт. `collector` собирает Docker-метрики; `otel-collector` принимает, записывает и передаёт spans; `tempo` принимает и хранит трассы во время нагрузки. CPU и RAM каждого процесса приведены отдельно для каждого режима в [results.md](results.md). Последующий просмотр в Grafana измеряется отдельно: [grafana.md](grafana.md).

## Целостность и границы результата

Все 11 завершённых опытов прошли проверки целостности. Независимый пересчёт 44 значений CPU совпал со сводкой. SDK, приёмник Collector, файловый экспорт и экспорт в Tempo согласованы по 159009 spans за всё время этих опытов; ошибок экспорта нет. Проверены связь HTTP → SQL, безопасные атрибуты и live Tempo. Графики: [ramp](plots/ramp.png), [stress](plots/stress.png), [soak-0](plots/soak-0.png).

По запросу пользователя длительная серия остановлена на двенадцатом опыте. `soak-0/trace` прерван, `soak-10` и `soak-20` не запускались. Выполнено по одному повторению; нагрузка замкнутая, поэтому CPU зависит от выполненной работы, RPS и ошибок. Серия оценивает расходы этих процессов в выделенной Colima VM (4 vCPU, 6.20 GB RAM); неопределённость между повторениями и причинный вклад инструмента отдельно не оценивались. Общие ресурсы ОС, VM и Docker daemon по контейнерам не распределены.

Исходные артефакты: `build/lab6/runs/20261124t091051-515010/`. [measurements.json](measurements.json) содержит завершённые опыты и явный статус прерывания всей матрицы. Предыдущая полная серия собственного recorder сохранена в истории Git; текущие таблицы описывают OpenTelemetry.
